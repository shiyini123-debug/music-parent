      ① 调音器 Tuner — 音准准不准?

      用途:孩子拉一个长音,看它准不准;也可以在练琴前看四根空弦是否调准。小提琴目标:G3 · D4 · A4 · E5。偏差在 ±10 音分 (cents) 内算很准,±25 内算可以。

      ② 速度 Tempo — 快了还是慢了?

      孩子弹的时候,你跟着拍子点下面的大按钮(或按空格键)。点 6–8 下就能算出每分钟几拍 (BPM),和这首曲子的参考速度比较。参考速度来自常见录音,只是参考:学生弹慢一些完全正常,更重要的是前后一致。

      ③ 跟唱练音准 Sing-along — 练你自己的耳朵

      点"出题"会响一个音,听完后跟着唱"啊——",保持住。指针在绿色区域就是唱准了。唱高或低一个八度都算对(男女声音域不同)。每天 5 分钟,耳朵会变灵,也就更容易听出孩子哪里不准。

      这个工具能做什么,不能做什么

      • 能:讲清楚每首曲子的背景、作曲家、情绪、结构,以及"弹得好"听起来是什么样;用麦克风判断音准(调音器)和速度是否稳定(打拍测速)。
      • 不能:自动对照乐谱找出钢琴上的错音。这需要专业的乐谱跟踪软件。替代方法:先听几遍名家录音("听一听"链接),再听孩子弹——你的耳朵会发现"不对劲"的地方,然后问孩子"这里老师怎么说的?"
      • 麦克风调音器适合单音(小提琴、人声)。钢琴同时按多个音时读数会跳动,这是正常的。

      关于内容

      • 曲目包括常见教材(铃木小提琴第1–2册、常见钢琴曲),以及标有"★ 孩子弹过"的曲子——它们来自2020–2026年和老师的往来邮件。孩子开始弹新曲子?告诉 Claude 曲名,就能加卡片。
      • 内容根据通行的音乐史资料编写。有争议或不确定的地方(比如"巴赫"的小步舞曲其实是佩措尔德写的、《致爱丽丝》的爱丽丝是谁)都已注明。参考速度是常见录音的大致速度,不是标准答案。
      • "听一听"会打开 YouTube 搜索,需要联网。其它所有内容离线可用。
      • "我的笔记"保存在当前这台设备的浏览器里,手机和电脑各存各的,不会上传。换浏览器或清除浏览数据会丢失。
      • "学琴之路"整页是私密的:正文含真实姓名,以加密形式(AES-256,密码派生密钥)嵌在页面里,输入密码后才显示;勾选"记住"后,解密结果保存在这台设备的浏览器里,点"锁定并忘记"即可清除。家里电脑的本地版本直接显示整页,并写着手机密码。曲目卡片是公开的,里面没有人名。
      • 作曲家人像和时代画作来自 Wikipedia / Wikimedia Commons(点图片可打开出处页面),第一次联网打开时加载,之后离线也能看。1840年以前的作曲家没有照片,显示的是油画或版画肖像。

      安装到手机和电脑 Install as an app

      • iPhone:用 Safari 打开网址 → 点底部"分享"按钮 → "添加到主屏幕" (Add to Home Screen)。
      • Android:用 Chrome 打开 → 右上角菜单 ⋮ → "安装应用" (Install app) 或"添加到主屏幕"。
      • 电脑 (Edge / Chrome):地址栏右侧会出现"安装"图标,点它即可。
      • 安装后像普通 app 一样从图标打开;打开过一次后,没有网络也能用(除了 YouTube 链接)。
